# CHC Technology — Image optimization

Apply SKILL.md and the language policy. This is a CHC adaptation, not a line-by-line translation.

1. Review contextual alt, decorative images, file size, formats, srcset/sizes and display dimensions.
2. Avoid lazy-loading the LCP image; inspect loading priority and width/height to prevent shifts.
3. Optimize copies, retain rights and necessary metadata, and compare visual quality.
4. Return image URL, issue, size and proposed fix; never attribute third-party images to CHC.
