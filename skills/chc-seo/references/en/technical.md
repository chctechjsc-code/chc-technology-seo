# CHC Technology — Technical SEO

Apply SKILL.md and the language policy. This is a CHC adaptation, not a line-by-line translation.

1. Inspect crawlability, indexability, HTTPS, URL structure, mobile, CWV, schema, JavaScript rendering and applicable submission mechanisms.
2. Cross-check status, redirect chains, canonical, noindex, robots and sitemap; crawl permission does not prove indexing.
3. Compare raw/rendered primary content. Distinguish lab/field, mobile/desktop and page/origin metrics.
4. Recommend evidence-backed changes; URL submission or server mutation must be within user scope.
