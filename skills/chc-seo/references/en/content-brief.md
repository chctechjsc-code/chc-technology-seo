# CHC Technology — SEO content brief

Apply SKILL.md and the language policy. This is a CHC adaptation, not a line-by-line translation.

1. Distinguish new content from improving an existing URL; inspect actual offerings before outlining.
2. Research the correct country/language SERP and record date, query and device where available. Without SERP access, mark the outline as a hypothesis.
3. Specify intent, audience, primary/secondary keywords, title/meta, headings, arguments, sources, internal links and CTA.
4. For hubs, cover real product/service groups. Mark keep/improve/add sections without imposing keyword density or arbitrary length.
