# CHC Technology — International SEO

Apply SKILL.md and the language policy. This is a CHC adaptation, not a line-by-line translation.

1. Build a URL/language/country matrix; distinguish client communication language from target market.
2. Validate language/region codes, self references, reciprocal tags, 200 URLs, canonicals and appropriate x-default.
3. Use vi or vi-VN to match Vietnamese targeting; use en for global English and regional variants only for real regional targeting.
4. Check content parity, prices, units, CTAs and links; do not canonicalize all translations to Vietnamese.
