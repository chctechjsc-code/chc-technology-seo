# CHC Technology — XML sitemaps

Apply SKILL.md and the language policy. This is a CHC adaptation, not a line-by-line translation.

1. Discover sitemaps from robots or supplied URLs; inspect indexes and relevant namespaces.
2. Check absolute URLs, status, canonical, indexability, duplicates and evidence for lastmod.
3. Compare discovered important URLs against sitemap coverage; distinguish unknown coverage from confirmed omissions.
4. Generate only eligible canonical URLs and split according to current protocol limits; provide validated XML.
