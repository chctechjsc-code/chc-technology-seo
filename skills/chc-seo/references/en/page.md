# CHC Technology — Single-page analysis

Apply SKILL.md and the language policy. This is a CHC adaptation, not a line-by-line translation.

1. Inspect raw and rendered HTML when JavaScript matters; record final URL, status, canonical, robots and language.
2. Review title, description, headings, search intent, internal links, images and structured data.
3. Separate performance measurements from HTML-based hypotheses; do not infer INP from source code.
4. Return strengths, located issues, proposed title/meta edits and acceptance checks.
