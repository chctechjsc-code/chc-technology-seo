# CHC Technology — SEO change tracking

Apply SKILL.md and the language policy. This is a CHC adaptation, not a line-by-line translation.

1. For a baseline, store timestamp, canonical URL, status, title/meta, headings, canonical, robots and schema.
2. Compare matching URLs and collection conditions; filter known noise while retaining originals.
3. Separate content/technical changes from collection failures; prioritize unexpected noindex/canonical/redirect changes.
4. Return diffs and history; a one-off command does not create a scheduled monitor.
