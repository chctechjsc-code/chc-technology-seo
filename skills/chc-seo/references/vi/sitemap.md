# CHC Technology — Sitemap XML

Áp dụng quy tắc chung trong SKILL.md và chính sách ngôn ngữ. Đây là quy trình CHC biên soạn lại, không phải bản dịch từng dòng.

1. Khám phá sitemap từ robots hoặc URL đã cung cấp; đọc sitemap index và namespace liên quan.
2. Kiểm tra URL tuyệt đối, status, canonical, indexability, trùng và lastmod có căn cứ.
3. So sánh URL quan trọng được phát hiện với sitemap; tách thiếu dữ liệu khỏi URL bị bỏ sót đã xác minh.
4. Khi tạo mới, chỉ đưa URL chuẩn đủ điều kiện và chia file theo giới hạn giao thức hiện hành; xuất XML kiểm tra được.
