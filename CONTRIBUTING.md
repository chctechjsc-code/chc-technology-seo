# Contributing to Claude SEO VN

This CHC Technology edition welcomes improvements to SEO analysis and Vietnamese/English localization.

1. Fork the repository and create a focused branch.
2. Use Python 3.11–3.14 for bundled runtime tools. Run `python scripts/chc_seo.py --help` for the public CHC CLI.
3. Run relevant checks and describe the results in the pull request.
4. Do not commit credentials, private client data or paid API output without permission.

Contributions to the CHC edition are released under the repository MIT License. Original work and its attribution are preserved in `provenance/upstream/` and `LICENSE`.
